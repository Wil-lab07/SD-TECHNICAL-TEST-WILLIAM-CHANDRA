**Situation:**

Di Pixel8Labs, kami menangani klien yang mengimplementasikan platform berskala besar dengan lonjakan pengguna aktif. Saat itu, sistem mengalami tingkat error sekitar 10% akibat tabrakan transaksi saat diakses 100+ pengguna secara bersamaan, serta waktu tunggu respon API yang lambat mencapai ~15 detik.

**Task:**

Tanggung jawab saya adalah mengeliminasi kegagalan transaksi konkuren tersebut, menata aliran data, dan memangkas waktu respon API agar pengalaman pengguna tetap cepat dan mulus.

**Action:**

Saya merancang arsitektur asinkron yang menghubungkan backend service berbasis Go dengan Google Cloud Pub/Sub. Permintaan berat dipindahkan ke antrean teratur (queue) untuk diproses oleh background worker, sehingga API dapat langsung mengembalikan respon sukses secara instan kepada pengguna

**Result:**

User-perceived wait time berhasil dipangkas dari ~15 detik menjadi di bawah 1 detik, serta error rate akibat beban konkuren berhasil ditekan hingga 0%. Selain itu, optimasi batch processing (100+ data per eksekusi) yang saya terapkan pada modul lain berhasil memangkas biaya komputasi hingga 50%.

### Manfaat bagi Tim AYO:

Keahlian ini relevan untuk diterapkan pada ekosistem AYO dalam menangani lonjakan trafik saat banyak pengguna mengakses jadwal mabar, booking lapangan, atau mendaftar kompetisi secara bersamaan. 

Menjaga endpoint API tetap responsif di bawah 1 detik dan bebas dari risiko race condition.
