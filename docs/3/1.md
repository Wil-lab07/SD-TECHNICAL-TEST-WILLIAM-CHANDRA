Saya memiliki kecocokan yang kuat untuk posisi ini berkat pengalaman lebih dari 3 tahun di bidang backend engineering, dengan spesialisasi utama pada Golang dan PostgreSQL. 

Selama ini, fokus saya adalah membangun layanan REST API yang tahan terhadap beban konkurensi tinggi, menjaga integritas data transaksi, serta mengoptimalkan performa query.

Pengalaman saya mencakup perancangan sistem antrian (queue/background worker via Google Pub/Sub) yang memangkas latensi API dari belasan detik ke sub detik, penanganan race condition, hingga pengamanan endpoint dari request invalid maupun duplicate writes.   

Nilai Tambah & Kontribusi untuk AYO:

Fitur inti AYO—seperti jadwal mabar, booking lapangan, dan kompetisi—sangat bergantung pada backend yang responsif dan stabil pada jam sibuk. Saya dapat berkontribusi langsung dalam:

1. Mengoptimalkan performa query database (misal mitigasi heavy offset/unbounded pagination).

2. Memperkuat layer keamanan API melalui validasi input yang ketat dan rate limiting.

3. Menjaga reliabilitas transaksi data pendaftaran/booking, serta siap langsung produktif mengikuti ritme sprint tim engineering AYO sejak hari pertama.
